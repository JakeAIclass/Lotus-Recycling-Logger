Data Collection

Training data was collected at Lotus Recycling, Campbellfield VIC — Australia's only genuine full-recovery solar recycler. Real panel barcodes were photographed on-site and serial numbers manually recorded. This real-world dataset forms the foundation of the intelligence engine.

Pipeline

The full MLOps pipeline runs automatically via GitHub Actions on every push to main. Steps: preprocess new data → drift detection → model training → evaluation → artifact upload. Average pipeline runtime: under 2 minutes.
